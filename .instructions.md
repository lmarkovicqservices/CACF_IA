# CACF IA - Asistente Técnico de Ensilado

## Contexto del Proyecto
Este es un asistente de WhatsApp para la Cámara Argentina de Contratistas Forrajeros (CACF).
Responde consultas técnicas sobre ensilado, earlage, henolaje y henificación a socios validados.

## Stack Tecnológico
- **Lenguaje**: Python 3.14+
- **Framework**: FastAPI (>=0.115.6) + Uvicorn (>=0.34.0)
- **LLM**: OpenAI GPT-4o
- **RAG**: LangChain (>=0.3.13) + ChromaDB (>=0.6.0) + text-embedding-3-small
- **WhatsApp**: Meta Cloud API (webhooks)
- **Hosting**: DonWeb VPS con Docker

## Convenciones de Código
- Usar type hints en todas las funciones
- Async/await para operaciones I/O (API calls, DB)
- Pydantic v2 para validación de datos
- Configuración via variables de entorno (.env)
- Español para comentarios y documentación, inglés para código (nombres de funciones/variables)
- Docstrings en español

## Terminología del Dominio
- **Ensilado/Silaje**: Forraje conservado por fermentación anaeróbica
- **Earlage**: Ensilado de espiga de maíz (grano húmedo + marlo + chalas)
- **Henolaje**: Forraje pre-secado envuelto en film plástico
- **Henificación**: Proceso de deshidratación del forraje para heno
- **Materia Seca (MS)**: Porcentaje del forraje sin agua
- **Materia Verde (MV)**: Forraje tal cual se cosecha (con humedad)
- **Contratista Forrajero**: Profesional que presta servicios de cosecha y confección de reservas forrajeras
- **Bolsa de silo**: Envase plástico donde se almacena el silaje
- **Picado**: Proceso de corte del forraje para ensilado
