# Preguntas de prueba

Acá van los documentos con preguntas para evaluar el asistente (sin respuestas
esperadas incluidas en la base de conocimiento).

Esta carpeta es independiente de `data/documentos/`: los archivos acá **no**
se indexan en ChromaDB ni forman parte del contexto que el RAG recupera.
Sirven solo como casos de prueba manuales para correr contra el sistema y
revisar si las respuestas generadas son correctas.
